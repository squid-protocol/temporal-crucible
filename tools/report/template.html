3 · Repairs: when, and how close

Moderate · causes named by Fixes: trailers or found by blame

T7How long fixes took

How much closer than chance fixes land

Within one or two calls of a changed function, against same-sized functions in the same file. 1.0 (the line) means no pattern.

Which causing changes produce which fixes

Causing changePairsFix in the same functionMedian lag

Cause type is the first verb of the causing commit's subject.

Day 1 function B changes.
Months later a bug appears. The fix edits B itself about half the time.
When it does not, the fix is usually in a function that calls B, or in B's file: look there first.
So whatAfter a feature, repairs arrive late and scattered: widen the review. After a fix of a fix, they come back to the same function.
