Where the function edits went

Terms and confidence labels
SweepOne commit that edits more than 60 functions: a rename, an API conversion, a reformat. Usually planned and mechanical.
Organic changeOrdinary work: new features, refactors, new code, removals.
FixA commit that says it fixes something: a Fixes: trailer, or a fix-like subject.
CauseThe earlier commit a fix repairs, named in the fix or found by git blame. "Later blamed for a fix" means a commit was the cause of at least one fix.
StrongA counting rule, or a result that held on other projects.
ModerateRests on a label with known error, such as fix-like subjects.
