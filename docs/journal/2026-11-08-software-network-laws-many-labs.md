## Question

Which of the classic software-network laws (heavy tails, preferential attachment, hub persistence, centralisation,
decay, cycles and defects, the size confound, network metrics in defect prediction, security-patch locality) hold
across languages and decades, when tested the same way with null models?

## Why we asked

The call-network studies of 2026-11-08 mostly rediscovered published results; the literature tests each law on one
language and a few systems. A compile-free, multi-language instrument with history can test them all on one
pre-registered panel (programme steps 2 and 3).

## What we did

Registered in `docs/laws_hypotheses.md` before any panel repo is selected: eligibility rules and a seeded random
draw of 8 repos per language, one engine, OSV CVE labels, hand-validated fix classes, the ACC gate, null models,
process and change-coupling controls, forward validation, per-language random-effects synthesis.
