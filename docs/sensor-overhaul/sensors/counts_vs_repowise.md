# Files and functions: GitGalaxy vs repowise (black box), 2026-11-16

Scripts `tools/sensor/count_compare.py` (table below, `count_compare_output.txt`) and `tools/sensor/old_code_test.py` (`old_code_test_output.jsonl`; its ctags column counted C struct members as functions and is superseded by the table here). repowise 0.61.0 run as a published package in an isolated HOME (see `reach_vs_treesitter.md`); indexes of the same trees as the reach head-to-head. Counts are restricted to source files of the repository's main language; a function is a (file, bare name) pair; universal-ctags is an independent reference, not ground truth, and knows no COBOL or PL/I.

## Result
* **Files:** the two tools index nearly the same source files in Go, Java, Rust, Python and TypeScript (within 1 to 6%). GitGalaxy indexes fewer C files where it skips vendored or third-party directories (redis 286 against 848: `deps/jemalloc` alone is 256 files; ndpi 363 against 430; libuv 335 against 369).
* **Functions, where both parse the same files:** they agree closely. Go: cobra 591 and 592, gin 1,284 and 1,310; Java gson 2,995 and 3,005; Rust 826 and 818, 1,775 and 1,883; Python httpx 962 and 917, fastapi 4,706 and 4,514. On the C files GitGalaxy indexed, both tools find 98 to 100% of ctags' functions (expat, redis, hiredis, ndpi); the large C differences (redis 7,289 against 18,447) are the skipped vendored directories, not parsing.
* **Where they differ otherwise:** flask (repowise finds 68% of ctags' functions, GitGalaxy 100%) and axios (both low against ctags, 44% and 61%: arrow functions and closures); zod (GitGalaxy counts more than ctags because it counts closures).
* **Old versions of a language (not a gap):** sphinx at 2008 (Python 2): repowise 589 functions, GitGalaxy 616, ctags 617 (95% and 100%); curl at 1999 (old C): 245 and 120 (ctags 130; repowise over-counts, 95% found by each). repowise's tree-sitter handles both; its parse flags errors on some files (curl-1999: 11 files, expat: 43 of 154, mostly macro-heavy C) but still recovers the functions.
* **Old languages (the real breadth gap):** Fortran (WRF): repowise indexes none of it, GitGalaxy finds 137 functions (ctags 135; 100% overlap). PL/I: repowise none, GitGalaxy 7. COBOL: both work (504 and 512 functions on CardDemo, same 72 files; repowise downloads a COBOL grammar on first use). JCL, HLASM, REXX and the other mainframe formats were not tested here. GitGalaxy has 78 language definitions; repowise documents 28 (plus downloadable grammars).
